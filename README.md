# Gmarc's Gen 1 Voxel Mod

A [gen1recomp](https://github.com/bryanthaboi/gen1recomp) mod.
Red, Blue and Yellow in 3D: the overworld and battles drawn as voxels, with the
classic tiles as their source of truth.

## Install

Import the release ZIP in the mod list, enable it, restart. Nothing else needed.

## Credit

Started life as Dramatic Shape. This is the maintained continuation.
